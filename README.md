# MAIHDA-Sedentarism-Childhood-Spain
R scripts and datasets

### Overview

Code for the study employing MAIHDA to understand the intersectionality of factors on sedentarism among children in Spain. Microdata obtained from the Instituto Nacional de Estadística (INE).

### Analysis datasets
R scripts and Stata do files.

- Users wishing to reproduce the analysis must obtain the data directly from the **Instituto Nacional de Estadística (INE)**.
- This work is part of research on childhood inequalities and sedentary behavior, supported by the Project **EVERYMOVE**.
